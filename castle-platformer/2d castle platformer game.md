# Rampart: 2D Castle Platformer

A finished, self-contained side-scrolling platformer set in a castle, with graphics and sound created in code and a polished interface.

## Assets
All art (characters, tiles, animation frames) is produced procedurally in code. No external downloads or libraries. Blender isn't available.

## How the player moves
- Running left and right that speeds up and slows down with some weight to it.
- A jump, plus a second jump in mid-air.
- Landing on an enemy's head defeats it.
- Health and respawning: falling into a pit or touching a hazard costs health and sends the player back.

## The level
- A castle course with changes in height, floating ledges and enemies that walk back and forth on patrol.
- A flagpole at the far end; touching it plays a win sequence.

## Screens and HUD
- A title screen with an original logo and crest, for example crossed swords.
- Health, score and level progress shown neatly in the top-left corner.
- A win screen summarising how the player did.

## Sound
- Background music in a chiptune/castle style and custom jump and stomp effects, generated with the Web Audio API or synthesized clips.
