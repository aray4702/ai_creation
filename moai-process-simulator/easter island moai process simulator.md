# 复活节岛摩艾石像：开采、雕刻、运输与竖立全流程模拟

研究复活节岛（Rapa Nui）摩艾石像的历史、考古与运输原理，用前端 3D 技术做一个分步骤的互动动画模拟。

## 五个阶段
1. **开采：** 岛民在 Rano Raraku 火山凝灰岩山体上切割、剥离石料。
2. **雕刻：** 工匠在岩体上逐步雕出石像的面部、头部和躯干。
3. **运输：** 采用考古实验验证的“行走摩艾”方案，三组绳索左右交替拉动，让直立的石像摇摆前进。
4. **竖立：** 用木杠杆撬动、石块垫高、绳索牵引，把石像安全竖立到祭坛（Ahu）上。
5. **戴帽：** 搭建木质斜坡，岛民用绳索把红色的普卡奥（Pukao）石帽滚上石像头顶戴好。

## 环境与交互
- 还原复活节岛的自然景观、海洋、阳光与风。
- 许多岛民角色在协同拉绳、发力。
- 底部有进度条和阶段切换按钮，可 360 度旋转视角观察每个细节。
