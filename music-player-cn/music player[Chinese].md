# macOS 原生音乐播放器

开发一款 macOS 原生音乐播放器，界面风格参考 Apple Music，但不使用 Apple 的 Logo、图标、字体等受版权保护的内容。

## 功能
- **主界面：** 精选专辑网格、推荐歌单和艺术家浏览页面。
- **播放控制：** 底部固定播放栏，支持拖动进度条、调节音量、播放/暂停、上一首/下一首。
- **迷你模式：** 一键切换到独立的浮动迷你播放器窗口。
- **队列与收藏：** “接下来播放”队列管理，以及红心收藏的实时切换。
- **界面细节：** 侧边栏可一键展开/折叠，整体采用 macOS 原生磨砂玻璃质感。
- **音频：** 内置本地合成的示范音源，没有导入外部文件时也能正常播放。

**交付方式：** Swift Package（`Package.swift` + `Sources/`），只装 Command Line Tools 也能用 `swift build` / `swift run` 编译运行，也可以直接用 Xcode 打开。
