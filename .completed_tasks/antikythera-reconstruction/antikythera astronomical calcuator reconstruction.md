Build an interactive 3D scientific reconstruction of the ancient Greek Antikythera Mechanism using Three.js and WebGL.

### Requirements:
1. **Exploded 3D Model Inspection:**
   - Render the complex multi-gear internal structure inspired by historical fragments of the world's oldest astronomical computer.
   - Allow users to explode the model view to inspect internal gear trains, differential gears, and drive handles.
2. **Educational Component Annotations:**
   - Make individual gear wheels clickable; displaying popup detail cards explaining each gear's tooth count, function, and mechanical purpose.
3. **Astronomical Calculations:**
   - Implement interactive controls to compute solar position, lunar phase cycles, and eclipse predictions driven by turning the manual hand crank mechanism.
