# Animated Chinese Ink-Wash Canvas (HTML5 Canvas)

使用 HTML5 Canvas 与 JavaScript 生成一段充满中国传统水墨画意境的动态长卷动画。

## 场景分镜剧本（Storyboard）

1. **第一幕（落墨）**：画卷初开为一片纯白宣纸，一滴浓墨从上方落于纸面，缓慢以水墨扩散算法晕染开来。
2. **第二幕（群山）**：扩散的墨迹向下方演化，逐渐凝结并勾勒出层峦叠嶂、远近交错的写意群山。
3. **第三幕（江河）**：群山峡谷间奔涌出一条大江，辅以水流粒子与声效（可选），远山间伴有若隐若现的飞鸟与日出轮廓。
4. **第四幕（人间）**：江水两岸逐渐浮现出江南水乡建筑，包含飞檐、层层屋瓦、水上划过的舟楫以及岸边的烟花特效。
5. **第五幕（风暴）**：天空骤变，远处乌云以浓墨翻滚袭来，伴随画面闪电与风雨交加的水墨特效。
6. **第六幕（白鹤）**：一只白鹤破开浓密乌云冲天而起，画面音乐与特效骤然归于安详宁静。
7. **第七幕（归依）**：天空展现日月同辉与银河星辰，所有画面元素与色彩向中心汇聚缩回，最终凝结回最初的一点浓墨，画面收尾。
