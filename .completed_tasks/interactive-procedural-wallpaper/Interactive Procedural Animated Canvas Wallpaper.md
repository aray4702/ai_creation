# Interactive Procedural Animated Canvas Wallpaper

Create a lightweight, single-file HTML5 Canvas procedural animated wallpaper with ambient fluid background dynamics and interactive particle fields.

## Visual & Technical Requirements
- **Generative Shader / Canvas Effect**:
  - Procedural noise-driven organic flow (Simplex/Perlin noise) creating smooth, looping background color waves.
  - Ambient glowing particle field drifting gracefully across the screen.
- **Interactivity**:
  - Mouse movement creates subtle ripple/repulsion fields in the fluid background and particle paths.
  - Click to cycle color palette presets (e.g., Deep Space Cyberpunk, Golden Hour Aurora, Oceanic Abyss).
- **Optimization**: Zero external dependencies, minimal CPU/GPU overhead, and responsive resolution auto-scaling.
