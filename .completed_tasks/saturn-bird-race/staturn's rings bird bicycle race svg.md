# Task 05 Prompt: 土星环自行车大赛 SVG 矢量动画

请使用原生纯 SVG（纯 HTML/CSS/SVG 或少量原生 JS）制作一个极其精致且富有幽默创意的交互矢量动画。

### 详细要求：
1. **比赛角色：**
   - 参赛者为三只不同种类的鸟类：**几维鸟（Kiwi）**、**渡鸟/乌鸦（Raven/Crow）** 和 **鹈鹕（Pelican）**。
   - 每只鸟的造型要准确且生动，骑着不同样式的自行车（Bicycles）在环形轨道上奋力竞速。
   - 包含真实的骑行脚踏动作、车轮旋转及车身起伏动画。

2. **场景与天体背景：**
   - 赛道为巨型**土星环（Saturn's Rings）**。
   - 背景展现浩瀚星空，远处可看到清晰的木星（Jupiter）、太阳（Sun）、地球（Earth）及火星（Mars），天体比例与光照色彩协调美观。

3. **交付要求：**
   - 纯矢量 SVG 输出，流畅不卡顿，代码结构清晰。
