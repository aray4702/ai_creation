# Full Arcade Kart Racing Game

Develop a complete single-prompt 3D arcade kart racer in a single HTML file using WebGL/Three.js.

## Game Features
- **Roster & Characters**: Custom racer characters (e.g., Blaze, Zippy, Toadley) with unique kart models and color schemes.
- **Track Design**: Loop track with surface elevation changes, visual track borders, boost pads, and scenic backdrop elements.
- **Arcade Mechanics**:
  - Responsive driving physics with drift mechanics, collision response, and speed boosts.
  - Dynamic item mystery boxes scattering power-ups across the track.
- **UI System**: Live leaderboard, lap counter, lap timer, speed gauge, and mini-map overhead display.
