# Multi-Agent Painterly Animated Music Video Engine

Build a complete 2.5-minute animated music video in a single WebGL/Canvas application given an input song track and lyrics.

## Architecture & Visual Mechanics
- **Sub-Agent Pipeline**: Architect scene rendering modules operating across timed keyframes mapped to musical beats and lyric timestamps.
- **Painterly Visual Style**:
  - Implement dynamic brush stroke canvas shaders giving every scene an organic, hand-painted aesthetic.
  - Animate character motions, environmental shifts, and camera pans with impressionistic painted textures.
- **Audio Synchronization**:
  - Web Audio API integration synchronizing visual transitions, stroke flow rates, and lighting shifts to the audio spectrum and beat hits.
  - Embedded audio playback controls with live wave spectrum visualization.
- **Output**: Pure executable JavaScript/HTML file containing all shaders, procedural art generators, and audio sync logic.
