# 3D Action Adventure Fox Game

构建一个 3D 动作冒险游戏，主角是一只像小狐狸一样的生物，有着巨大而富有表现力的琥珀色眼睛以及高高竖起的耳朵，并且它还会带着一盏灯笼。

## 核心机制与场景风格
- **角色设计**：小狐狸模型需手持一盏能发出暖色动态微光的灯笼，具有灵动的耳部动画与尾巴物理效果。
- **操作与技能**：
  - **基础移动**：流畅的 3D 角色控制器与镜头跟随。
  - **攻击机制**：触发尾巴/身体旋转扫击（Spin Attack），可打击并击飞场景中的木箱与道具。
  - **跳跃机制**：支持多段跳跃（Double/Multi-jump）与空中落体缓冲。
- **场景视觉**：采用带有梦幻色彩的童话风格场景，具备动态柔和光影与发光粒子微粒。
