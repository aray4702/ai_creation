# Hand-Animated Procedural Pixel Art Wizard Character

Create a self-contained HTML/Canvas application displaying an animated retro pixel art wizard character generated entirely through code without external image files.

## Visual & Animation Mechanics
- **Palette**: Strict 24-color retro pixel art palette.
- **Animation States**:
  - **Idle State**: Breathing animation, tunic swaying, staff floating.
  - **Charge State**: Gathering magical energy, glowing aura particles, floating robe physics.
  - **Spell Cast**: High-energy particle beam release, dynamic screen shake, flash lighting, and particle dissipation.
- **Render Quality**: Crisp pixel-grid scaling with retro CRT scanline overlay options.
