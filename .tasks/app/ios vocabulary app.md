# iOS Native Vocabulary Learning App

Build a complete native iOS vocabulary application using Swift and SwiftUI with the following feature spec.

## Functional Specification

1. **Vocabulary Sets & Study Goals**:
   - Provide pre-loaded vocabulary lists for CET-4, CET-6, TOEFL, and GRE.
   - Allow users to set custom daily word targets (e.g., 25 words/day).

2. **Flashcard Interface**:
   - Interactive 3D flip animation for flashcards.
   - Front: Word, IPA pronunciation guide, audio playback button.
   - Back: Chinese definitions, example sentences, synonym/antonym lists.
   - Rating actions: "Know" vs. "Don't Know" to feed into a spaced repetition scheduling system.

3. **Search & Collection**:
   - Instant search bar with word definitions and direct bookmarking/favorites functionality.

4. **Quiz & Practice Modes**:
   - Multiple-choice definition matching.
   - Listening comprehension quizzes with audio playback.
   - Post-quiz summary showing accuracy percentage, time taken, and a list of missed words for review.

5. **Analytics & Settings**:
   - Daily progress tracking dashboard with streak indicators and achievement badges.
   - Voice accent toggle between US and UK English.
