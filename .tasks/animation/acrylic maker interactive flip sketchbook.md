# Acrylic Marker Interactive Flip Sketchbook

Build a single-file JavaScript application that ingests photos and converts them into a stylized, turnable physical sketchbook drawn in bold acrylic marker art.

## Features & Shader Pipeline
- **Stylization Filter**: Canvas/WebGL filter converting input photograph lighting and contours into vibrant, textured acrylic paint and thick marker line strokes.
- **Interactive Sketchbook UI**:
  - 3D page-flip animation mimicking physical paper curvature, shadow casting, and page thickness.
  - Bound sketchbook frame with spiral wire/leather texture and touch/drag page dragging.
- **Gallery**: Multi-page layout parsing multiple photo inputs into a cohesive artistic visual travel journal.

**Execution note:** Include several procedurally generated sample "photos" so the sketchbook is fully demoable before the user uploads their own images.
