# Task 07 Prompt: Unity 3D + C# 侏罗纪主题《我的世界》方块沙盒游戏

请为 Unity 3D 游戏引擎编写一套完整的 C# 脚本架构（配合 Claude Code / Agent 自动构建流程），开发一款侏罗纪世界背景的《我的世界》（Minecraft-style）第一人称体素沙盒游戏。

### 核心系统与功能要求：

1. **体素地形与世界生成 (Voxel World Generation):**
   - 基于 Perlin Noise 算法程序化生成 3D 方块地形，包含山脉、泥土、石头、树木与大型水域（湖泊/海洋）。
   - 支持动态方块破坏（Mining）与方块放置（Building）。

2. **武器与装备系统 (Weapons & Physics):**
   - **加特林机枪 (Gatling Gun):** 高射速、具备开火音效、弹道光束，并能直接击碎/开采射击到的地形方块与树木。
   - **手雷 (Grenades):** 投掷物理轨迹，落地爆炸产生爆破粒子特效，可将周围的树木和方块炸毁。

3. **恐龙生态与 AI (Dinosaurs AI):**
   - 场景中生成不同体型的恐龙（如大型陆地恐龙、水下巨型恐龙）。
   - 包含恐龙咆哮环境音效、受击血量反馈与消亡动画。

4. **天气与环境系统 (Dynamic Weather System):**
   - 动态昼夜交替（天空盒与日光渐变）。
   - 动态天气切换：下雨特效（雨滴粒子与下雨声效）、闪电光效。

5. **玩家控制 (Player Movement):**
   - 第一人称视角控制、移动、跳跃、按键切换飞行模式（Fly Mode）。
