# Antikythera Mechanism Underwater Exploration Game

Create an immersive deep-sea diving exploration game centered around discovering the Antikythera mechanism shipwreck, contained within a single HTML file under 3MB.

## Gameplay & Audio-Visual Specs
- **Underwater Environment**: Atmospheric ocean depth rendering with volumetric caustic light rays, floating organic debris, and parallax seabed terrain.
- **Diving Mechanics**: Smooth physics-based diver propulsion, flashlight beam casting, and salvage tools.
- **Interactive Mechanical Puzzle**:
  - Fully modeled 3D/2D procedural gear mechanism representing the Antikythera computer.
  - Clean gear-tooth interlocking physics allow players to rotate dials to calculate astronomical cycles.
- **Procedural Audio**: Complete underwater ambient soundscape and gear mechanical clicks synthesized live via Web Audio API.
