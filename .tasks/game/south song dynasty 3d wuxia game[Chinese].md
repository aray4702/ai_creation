# Task 03 Prompt: 南宋古都 3D 武侠动作游戏

请开发一款以南宋古都（临安/杭州）为背景的 3D 武侠动作游戏（单文件 Web 游戏）。

### 详细要求：
1. **场景与氛围：**
   - 场景包含南宋古都街巷、古建筑群、庭院住宅、荷花池（含荷叶与盛开荷花）及飞檐阁楼。
   - 内部建筑可进入，室内挂有字画、摆放桌椅并有 NPC 角色。
   - 包含昼夜交替/夜景模式：到了夜晚，街巷两侧挂着的红灯笼会逐一亮起，营造逼真的古风意境。

2. **角色与动作机制：**
   - 玩家扮演一位白衣侠客，可在古巷与建筑间行走、奔跑、跳跃。
   - 场景中会实时刷新黑衣刀客（敌方 AI）对玩家进行追杀。
   - 具备完整的近战打击动作与打击感（包含击中光效/硬直）。
   - 支持切换多种攻击招式/技能组合，支持实时切换不同的武器（如长剑、弯刀等）。

3. **交付形式：**
   - 提供可在浏览器中无缝运行的独立 HTML 代码。
