# Godot 4 3D Jurassic Tank Game

使用 Godot 4 游戏引擎开发一款 3D 动作射击游戏。

## 游戏设定与玩法机制
- **背景主题**：侏罗纪时代。玩家驾驶一辆 3D 坦克在充满原始地形的地图中自由移动与瞄准射击。
- **NPC 与敌人**：
  - 地面上分布着多只恐龙（如霸王龙、三角龙），实现恐龙的 3D 随机漫步与碰撞体。
  - 天空中翱翔着翼龙以及巡逻的 UFO 飞碟。
  - 坦克射击击中 UFO 时，UFO 头顶需显示血条扣减，血量归零后触发销毁爆炸特效。
- **环境要素**：
  - 场景中包含 3D 树木、巨石以及散落的“神秘物体（Mysterious Artifact）”。
  - 当玩家操控坦克靠近“神秘物体”时，触发环境状态切换（如天空盒颜色实时变色/昼夜切换特效）。
