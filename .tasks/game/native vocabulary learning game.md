Create a native vocabulary learning application in Swift/SwiftUI for macOS and iOS featuring a modern, distraction-free UI.

### Features:
1. **Flashcard Learning System:**
   - Interactive flashcards displaying foreign word, phonetics, audio pronunciation button, and sentence example trigger.
   - Reveal translations, view detailed word breakdowns, synonyms, and add to personal notes.
   - Options to mark words as "Mastered" or save to "Favorites".
2. **Gamification & Practice:**
   - **Quick Quiz Mode:** Multiple-choice vocabulary tests with instant right/wrong visual feedback and detailed post-quiz scoring (accuracy rate, speed, review queue).
   - **Achievements:** Earn and display unlockable achievement badges based on learning streaks and daily goals.
3. **Customization & App Settings:**
   - Daily word target configuration, regional pronunciation selection (US / UK English accent).
   - Dark mode toggle with seamless theme switching and custom accent colors.
