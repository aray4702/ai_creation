# Task 02 Prompt: 2D 户型图构建 3D 可自由探索空间

请根据我提供的室内 2D 房型平面图（Floor Plan Image），使用 Three.js / WebGL 构建一个真实的、可自由探索的双层/多房间 3D 室内建筑空间。

### 详细要求：
1. **空间还原：**
   - 准确还原平面图中的房间布局、空间比例、墙体结构、门窗位置及家具摆放。
   - 包含完整的房间区域：客厅（含沙发、电视、茶几、绿植）、厨房（含灶台、油烟机、橱柜）、餐桌椅、卧室、卫生间以及带拉门/搁板的杂物间。
   - 包含复式/双层楼梯，可通过楼梯自由上下二楼探索各个卧室与卫生间。
   - 逼真的材质贴图（木地板、瓷砖、墙面材质）以及室内环境光源与窗外自然光线。

2. **第一人称探索控制（FPS Navigation）：**
   - 支持第一人称视角（First-Person View）进入房间自由漫游。
   - 使用键盘 `WASD` 或方向键控制前后左右移动，使用鼠标控制相机视线旋转。
   - 包含碰撞检测，防止穿墙。

3. **交付形式：**
   - 交付完整的单文件 HTML/JS 代码，可在浏览器中完美运行。
