# Procedural Castle & Fireworks Engine for Blender Python API

Write a self-executing Python script for Blender (`bpy`) that procedurally builds a complete 3D medieval castle on a lake with animated fireworks.

## Generation Requirements
- **Castle Architecture**:
  - Procedurally generate stone walls, crenellations, round turrets, drawbridge, central keep, and slate roof geometry using Geometry Nodes or pure Python mesh creation.
- **Environment**:
  - Procedural water plane surrounding the castle with specular reflections, ripples, and shoreline mesh blending.
- **Particle Fireworks & Rendering**:
  - Particle system simulating ascending rocket trails and multi-colored burst explosions in the night sky.
  - Set up camera path framing, cinematic lighting, material shaders, and trigger background render sequence with build time-lapse logging.
