# Image-to-3D Sci-Fi Spaceship Frontend Model

请使用前端 WebGL 渲染技术（如 Three.js）根据给定的科幻宇宙飞船概念设计图，全代码复刻生成对应的 3D 宇宙飞船模型。

## 建模与渲染要求
1. **外形构造**：
   - 精准还原概念图中的飞船流线型主躯干与翼展。
   - 包含高精度的尾部推进器粒子喷雾/火焰特效（Thruster Plume）。
   - 细化外壳面板结构线、天线感应器以及载人舷窗。
2. **室内舱室透视**：
   - 支持点击面板切换查看飞船内部的不同舱室（如驾驶舱、生活舱、动力舱）。
   - 提供镜头自动推进并聚焦至指定舱室内部的过渡动画。
3. **视觉效果**：
   - 动态金属 PBR 材质（Metalness / Roughness Maps）。
   - 环绕飞船的漫游镜头与光影渲染。
