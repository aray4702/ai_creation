# Acrylic Marker Interactive Flip Sketchbook

A single-file JavaScript app that takes photos and turns them into a stylised sketchbook, drawn in bold acrylic marker art, whose pages you can turn.

## Stylisation filter
- A Canvas/WebGL filter that converts a photo's lighting and contours into vibrant, textured acrylic paint and thick marker strokes.

## Interactive sketchbook
- A 3D page-flip animation that mimics real paper: curvature, cast shadows and page thickness.
- A bound sketchbook with spiral wire or leather texture, and touch/drag page turning.

## Gallery
- A multi-page layout that arranges several photos into one cohesive illustrated travel journal.

## Execution note
Include several procedurally generated sample "photos" so the sketchbook can be demonstrated before the user uploads their own images.
